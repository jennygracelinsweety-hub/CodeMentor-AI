# CodeMental AI

## Description
CodeMental AI is a student-focused AI-powered coding support platform developed to help learners improve their programming skills through guided assistance and a more engaging learning experience.

## Objective
The main objective of this project is to make coding practice easier, smarter, and more interactive for students by using AI-based support.

## Features
- AI-based coding guidance
- Beginner-friendly learning support
- Interactive and engaging platform idea
- Designed for student coding improvement
- Academic mini project presentation

## Technologies Used
- HTML
- CSS
- JavaScript
- AI Tools

## Project Use
This project can be used as a concept for student coding support, guided practice, and skill development.
